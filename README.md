# Django Weather Application

A web application built using Python and Django to check real-time weather conditions for any city.

## Project Overview
This project is developed as part of the Unit-3 Django assignment. It fetches and displays live weather data (such as temperature, humidity, and weather descriptions) using a web interface.

## Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML, CSS
* **Version Control:** Git & GitHub
